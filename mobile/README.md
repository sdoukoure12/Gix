# README — Dossier mobile (Unity AR)

Ce dossier contiendra le projet Unity pour l'application mobile AR de Gix.

## Structure attendue

```
mobile/
├── Assets/           # Assets Unity (scènes, scripts C#, préfabs, etc.)
├── Packages/         # Packages Unity (manifest.json)
└── ProjectSettings/  # Paramètres Unity du projet
```

## Prérequis

- Unity 2022 LTS ou supérieur
- AR Foundation (com.unity.xr.arfoundation)
- ARKit (iOS) / ARCore (Android)

## Compilation

Ouvrir le dossier `mobile/` avec Unity Hub.
